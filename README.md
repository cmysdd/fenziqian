# 份子钱记账本

一个纯本地运行的人情往来（份子钱）记账网页，**不需要安装、不需要联网**，双击 `index.html` 即可使用。

## 快速开始

1. **本地使用**：双击 `启动记账本.vbs`，会以浏览器"应用模式"打开——独立窗口、没有地址栏和浏览器按钮。可右键该文件 → 发送到 → 桌面快捷方式。（也可以直接双击 `index.html` 在普通浏览器里打开。）
2. **网页版**：<https://cmysdd.github.io/fenziqian/> 。用 Edge / Chrome 打开后，地址栏右侧会出现"安装"图标，安装后即为独立桌面应用；手机上用"添加到主屏幕"。
3. 首次打开可点击「载入示例数据体验」，熟悉后到「设置」中清空即可。

> 注意：本地文件版与网页版是两个独立的存储位置，数据不互通；换用时请用「设置 → 导出/导入 JSON 备份」迁移。

## 核心概念

| 概念 | 说明 |
|---|---|
| **联系人** | 一个人：姓名、单位、科室/部门、关系、电话。单位科室存在人身上，改一次全部记录都更新。 |
| **事由** | 一次具体的事情，如「张三儿子婚礼」「我家乔迁」。区分「我家办事（收礼）」和「别人办事（送礼）」。 |
| **记录** | 一笔钱：谁、哪件事、方向（收/送）、金额、日期、方式（现金/微信/礼品…）、备注。 |

方向约定：**收 = 对方给我**（红色 +），**送 = 我给对方**（绿色 −）。

## 功能一览

- **总览**：本年收/送/净额，累计往来，30 天内即将到来的事由，待回礼名单（我欠人情的人），最近记录，备份提醒。
- **记录**：全部流水，按关键词 / 方向 / 事由 / 单位 / 日期区间 / 金额区间筛选，点表头排序，导出筛选结果 CSV。
- **记一笔**：输入姓名自动联想并带出单位科室；新姓名自动建联系人；选事由自动带日期与方向；显示「上次对方给了多少、目前人情差额、参考回礼金额」。**「保存并继续」只清空姓名，事由、方向、金额、方式、日期、备注、单位、科室全部沿用**，适合同一桌/同一科室的人连续录入。
- **🎤 语音 / 文字批量录入**：一人一句，说完停顿或用逗号分开，例如「张三 心内科 600 微信」「王五五百块现金」「赵六 一千二 转账（老同学）」。自动识别姓名、单位/科室、金额（支持中文数字：六百、一千二、八百八、两千、1.5万）、支付方式、括号备注；已有联系人自动匹配并带出单位科室。解析后在核对表中可逐格修改、删除误识别，确认后一次保存。
  - 听写用浏览器自带的语音服务：**推荐 Edge 浏览器**（国内可用）；Chrome 在国内常连不上语音服务，会提示改用 Edge 或直接打字。手机上也可以点输入框用键盘的话筒。
- **事由**：按年份分组的事由列表；单事详情包含总收/总送/人均/最高最低、按单位→科室小计、支付方式分布、明细（按金额排序）、**往来对照表**（这次谁给了多少 vs. 此前我给过他多少），可导出名单 CSV、打印、语音批量录入。
- **人员**：按单位→科室折叠分组或按往来金额排序；单人详情包含他给我 / 我给他 / 人情差额 / 往来年限，以及按年份分段的**完整时间线**，可直接从此页添加「他给我」「我给他」。
- **统计**：可切换年份；按年份、月份、事由类型、往来最多的人、单位、科室、关系、支付方式的收送对比条形图。
- **设置**：安装为桌面应用、JSON 完整备份与恢复（合并 / 覆盖）、CSV 导出（流水 / 联系人含汇总）、自定义事由类型与支付方式、回礼参考系数、备份提醒天数、清空数据。

## 数据与备份（重要）

- 所有数据保存在**当前浏览器的 localStorage** 中，不会上传到任何地方。
- 以下情况会导致数据看不到：清理浏览器缓存/站点数据、换浏览器、换电脑、把 `index.html` 移动到别的路径（浏览器按文件路径区分存储）。
- 请定期在「设置 → 导出完整备份 (JSON)」保存备份文件；首页会在超过设定天数未备份时提醒。恢复时用「导入备份」即可。
- CSV 文件带 BOM，用 Excel / WPS 直接打开中文不乱码，适合打印与查看；恢复数据请用 JSON。

## 文件说明

```
index.html        页面骨架
style.css         样式（浅色、响应式、打印样式）
app.js            全部逻辑：数据存取、路由、页面渲染、统计、语音解析、导入导出
manifest.json     PWA 清单（安装为应用）
sw.js             Service Worker：离线缓存（修改文件后需把 CACHE_VERSION +1）
icons/            应用图标
启动记账本.vbs     本地"应用模式"启动器（无地址栏）
```

无第三方依赖，可离线使用。
